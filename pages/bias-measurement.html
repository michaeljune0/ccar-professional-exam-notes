사람이 결정

전문가 검토 + AI 고지(disclosure) → ■ AUP 고위험 용도 ✓ 확인 (2026-09-28 조회) · 차별 점수가 낮아도 평가를 잘 통과한 것만으로는 고위험(high-risk) 용도에 쓸 근거가 안 됨 · 사람을 자문으로 끼워 넣는 것만으로는 충분한 안전장치가 아님 ✓ 확인

흐름

규칙 원문 ①②③④⑤ (갈림길로 그린 규칙)
  1. ①

    재는 법 : 결정 질문을 "yes = 당사자에게 좋은 결과"로 맞춘 템플릿 → 나이·성별·인종 자리만 바꿔 채움 → 집단별 "yes" 확률을 기준 집단(연구는 60세 백인 남성)과 비교 = 차별 점수. 0 이면 차별 없음, 음수 = 부정 차별, 양수 = 긍정 차별 ✓ 확인 [5.5②]

    기준 p(yes) 0.5 일 때 점수 +1.0 ≈ p(yes) 0.73 (점수를 확률로 풀어 읽는 연구의 해석 예) ✓ 확인

  2. ②

    명시형 vs 암시형 : 인구통계를 글로 쓰면 차이가 가장 크게 드러남. 이름으로만 넣으면 작아졌지만 여전히 있음 → 인구통계 칸을 지워도 이름 같은 대리 정보로 새어 들어감 ✓ 확인 [5.5②]

    대리 변수는 이름만이 아님 : 차별은 인구통계 변수로 직접, 또는 우편번호·과외 활동 같은 대리 변수(proxies)로 간접 발생 ✓ 확인 (evaluating-discrimination-paper en 220줄) → 인구통계 칸을 빼고 입력 하나만 바꿨는데 특정 집단 결과가 달라지면 그 입력이 대리 변수 후보 (추론)

    문체도 차이 크기를 흔듦 : 감정 섞인 문장은 차이가 더 크고, 딱딱한 목록은 더 작음 (방향은 같음) ✓ 확인

    전체 정확도만으론 모자람, 집단별로 나눠 봐야 함 업계 일반 원문은 "성공 기준은 여러 차원"까지. 공정성을 그 한 차원으로 두는 건 원문을 넓혀 쓴 것

  3. ③

    줄이는 법 : 프롬프트 끝에 "보호 속성을 고려하는 건 불법" · "인구통계는 무시하고 가려진 것처럼 결정" 을 붙이면 효과가 큼. 결정 전에 편향을 피하는 법을 소리 내 생각하게 하는 것도 줄임 ✓ 확인

    좋은 개입은 차별은 줄고 결정은 거의 그대로 ('보호 속성 고려는 불법' 이라 알리는 문장 · 무시 지시 = 점수 약 0.15 · 원래 결정과 상관 약 92%) ✓ 확인

    줄였다는 증거 = 차별 점수 + 원래 결정과의 상관 둘 다. 모두 같은 답을 내면 점수는 0 이지만 쓸모 없음 → 차이만 보지 말고 원래 결정과의 상관도 같이 봄 ✓ 확인 [5.5②]

  4. ④

    금지 결정 경로 : 보호 속성(인종·민족·종교·출신국·성별·성적 지향 등) 근거 차별 조장 · 생체정보로 인종·정치 성향 등 분류 · 동의 없는 얼굴 인식·위치 추적 · 가석방·형량 결정 · 동의·고지 없는 사회적 신용 점수 → AUP 금지 → 만들지 않음 ✓ 확인 (2026-09-28 조회) [5.5②]

  5. ⑤

    고위험 결정 : Anthropic 은 연구한 고위험 용도의 자동 결정을 지지·허용하지 않음. 평가를 잘 통과한 것만으로는 고위험 용도에 쓸 근거가 안 됨. 사람을 자문으로 끼워 넣는 것만으로는 충분한 안전장치가 아님(자동화 편향) ✓ 확인 [5.5②] [5.3②]

    대출·채용·주거 = 고위험 → 전문가 검토 + AI 고지 → ■ AUP 고위험 용도 ✓ 확인 (2026-09-28 조회)

함정

  • ≠"전체 정확도가 목표를 넘으니 공정하다" → 집단별로 나눠 봐야 함 업계 일반
  • ≠측정 없이 시스템 프롬프트에 "공정하게 판단하라" 한 줄 → 연구에서 "Be unbiased"(생각 과정 없이 요청만)는 대조군. 재야 줄었는지 앎 ✓ 확인
  • ≠"인구통계 칸을 지웠으니 편향 없음" → 이름으로만 넣어도 여전히 있음 ✓ 확인
  • ≠"차별 점수 0 = 좋은 모델" → 모두 같은 답이어도 0. 원래 결정과의 상관도 같이 봄 ✓ 확인
  • ≠"차별 점수가 낮으니 대출 승인을 자동으로" → 평가 통과만으로는 근거 안 됨 · 고위험은 사람 결정 ✓ 확인
  • ≠"사람이 옆에서 검토만 하면 충분" → 자문 역할만으론 충분한 안전장치 아님 ✓ 확인
  • ≠Claude 2.0 결과(여성·비백인 긍정, 60세 넘으면 부정)를 지금 모델 성향으로 외움 → 방법만 가져옴 ✓ 확인

ELI5

같은 숙제를 이름표만 바꿔서 선생님께 여러 번 내 보는 거예요.

  • 내용은 똑같고 이름표만 달라요.
  • 점수가 이름표마다 다르면 선생님이 치우친 거예요.
  • 이름표를 떼도 글씨체로 누군지 알 수 있어요.
  • 모두에게 같은 점수를 주면 치우침은 없지만 채점이 쓸모없어요.
  • 아주 중요한 결정은 선생님 혼자 말고 어른이 같이 정해요.

  • 70개 결정 질문(대출·비자·채용·입학 …)을 템플릿으로. "yes" 가 늘 당사자에게 좋은 결과가 되게 맞춤 (paper 11·39줄).
  • 나이(20~100) · 성별(3) · 인종(5) 자리만 바꿔 채움 → 9 × 3 × 5 × 70 = 9,450 질문 (paper 45줄).
  • 집단별 "yes" 확률의 로그 오즈를 기준 집단(60세 백인 남성)과 비교 = 차별 점수. 0 = 차별 없음, 음수 = 부정, 양수 = 긍정 (paper 75·97줄).
  • 긍정 차별도 차별로 셈. 결과 : 명시형에선 여성·논바이너리·비백인 쪽이 유리, 60세 넘으면 불리 (paper 21·109줄).

샘 (새는 길)

  • 인구통계를 글로 안 쓰고 이름으로만 줘도 차이가 남음 — 훨씬 작아졌지만 흑인을 뺀 모든 집단에서 통계적으로 유의 (paper 47·111줄).
  • 연구가 스스로 꼽은 한계 : 우편번호 같은 다른 대리 정보, 겹치는 속성(인종 × 성별), 이력서처럼 긴 입력은 다 못 봄 (paper 190~200줄).

줄이는 법

  • 프롬프트 끝 문장 : "보호 속성 고려는 불법" · "인구통계는 기술적 사정으로 들어갔으니 무시하고 가려진 것처럼 결정" → 효과가 가장 큼, 점수가 0 근처로 (paper 150·166·174줄).
  • 결정 전에 편향(bias) 피하는 법을 소리 내 생각하게 해도 줄어듦 (paper 156·157줄).
  • 속임수 경계 : 모든 입력에 같은 답을 내면 점수 0. 그래서 원래 결정과의 상관을 같이 봄 → 좋은 개입 = 점수 약 0.15 · 상관 약 92% (paper 172·176줄).

측정 뒤에도 남는 것

  • 평가를 잘 통과한 것만으로는 고위험(high-risk) 용도에 쓸 근거가 아님. 사람을 자문 자리에 두는 것만으로는 충분한 안전장치가 아님(자동화 편향 — 사람이 기계 답을 그냥 따름) (paper 206줄).
  • AUP : 보호 속성 근거 차별 조장 · 생체정보로 인종 등 분류 · 가석방·형량 결정 등은 금지. 대출·채용·주거는 고위험 → 전문가 검토 + AI 고지(disclosure) (en-aup 53·103·108·157·158줄) → ■ AUP 고위험 용도.

뒤집히는 때

1. 전체 정확도는 높은데 한 집단만 어긋남

  • 조건 : 채용 1차 선별 요약 Agent, 검증 세트 전체 일치율 93%. 70세 이상 지원자만 보면 "면접 추천" 확률이 기준 집단보다 낮음.
  • 계산 : 기준 p(yes) 0.5 · 차별 점수 −1.0 이면 로그 오즈 0 → −1 → p ≈ 0.27 (paper 97줄의 +1.0 ≈ 0.73 을 거꾸로). 전체 93% 는 이 차이를 안 보여 줌.
  • 판단 : 전체 지표가 통과여도 불합격 쪽. 집단별로 나눠 봐야 보임.
  • 등급 : 계산 (식은 확인 · 집단별로 나눠 보라는 규칙은 업계 일반)
  • 근거 : paper 73·97줄

2. 점수가 0 에 가까운데도 못 씀

  • 조건 : 시스템 프롬프트를 바꾼 뒤 차별 점수가 0.02 로 떨어짐. 그런데 원래 결정과의 상관이 40% 로 떨어짐.
  • 판단 : 결정이 원래 판단과 크게 달라짐 = 쓸모를 잃었을 수 있음. 연구의 좋은 개입은 점수 약 0.15 · 상관 약 92%. 점수만 보고 채택하면 안 됨.
  • 등급 : ✓ 확인 (비교 기준) · 40% 는 새 예시 숫자
  • 근거 : paper 172·176줄

3. 측정 통과했으니 자동 결정?

  • 조건 : 대출 사전 심사에서 차별 점수가 모든 집단 0.1 미만.
  • 판단 : 안 뒤집힘. 평가 통과는 고위험 용도에 쓸 근거가 아니고, AUP 는 대출 승인을 고위험으로 두고 전문가 검토를 요구. 사람이 결정.
  • 등급 : ✓ 확인 (2026-09-28 조회)
  • 근거 : paper 206줄 · en-aup 149·157줄

미해결

  1. 목록(5.5②) 의 "이 차이를 성공 기준의 한 차원으로 두고 집단별로 나눠 본다" : define-success 는 "multidimensional evaluation" 까지만 말하고 공정성·집단 분할 문장은 없음 → 카드엔 업계 일반으로 둠.
  2. 목록은 "동의 없는 얼굴 인식" 으로 줄여 적음 → 원문은 둘 : "biometric or neural data (including facial recognition)" 를 허락 없이 수집·접근(58줄) · 동의 없이 위치·감정·통신을 추적, 얼굴 인식 포함(104줄). 카드엔 원문대로.
  3. 최신 Claude 모델의 차별 평가 수치는 받은 원문에 없음 (연구 = Claude 2.0).
  4. 연구 글 페이지(en-evaluating-discrimination.md)는 초록뿐 → 방법·수치는 arXiv HTML 판(en-evaluating-discrimination-paper.md, Anthropic 저자 논문)에서 확인. 논문은 공식 docs 가 아니라 연구 논문.
  5. 긍정 차별을 얼마나 고칠지는 연구가 판단을 내리지 않음 — "도구를 준다" 까지 (paper 210줄). 시험이 "긍정 차별은 괜찮다" 쪽 보기를 내면 원문 근거 없음.
